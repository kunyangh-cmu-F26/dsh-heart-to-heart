# 知心聊天者 · dsh-heart-to-heart

在 DeepSeek Harness 的输入框里点「倾听」，就可以像发即时消息一样，想到哪儿说到哪儿。插件先把几段话留在输入框上方，等适合接话时再交给当前会话的模型和人设。

## 安装

面向 DSH 0.2.2 的桌面和 Web 输入框，已在 DSH 0.2.2-rc.1 Web 上验证。下载发行包，在下载目录运行：

```powershell
dsh plugin --profile web add ./dsh-heart-to-heart-0.1.0.tgz
```

把 `web` 换成你实际使用的 profile，安装后重新打开 DSH。卸载命令：

```powershell
dsh plugin --profile web remove dsh-heart-to-heart
```

## 怎么聊

- 打开「倾听」，照常按 Enter 或点发送，一段一段讲。「倾听」按会话记住开关。Shift+Enter 仍然是换行。
- 正在输入下一段时会继续等。问「你还在听吗？」等约 4 秒可短接一句。一般连发后的停顿约 12 秒可以接一句，听到「还有一件事」会把等待拉长到约 27 秒。「我还没说完」「先别回复」会继续等。短接之间至少间隔 35 秒。
- 如果句子听起来已经收尾，比如「后来我们就没再联系了」，停约 16 秒后会完整回应。直接问「你怎么看？」通常约 4 秒就能接话。
- 随时点「我说完了」交话。完整回应会先接住感受，再聊它怎么看。没有直接索要建议时，先问你想不想听。关掉开关时，有待发送的片段会先合在一起请 DSH 接话。
- 计时取决于最后一段的措辞和停顿。含糊的收尾有时需要点「我说完了」。输入下一段会取消尚未开始的自动发送，已经交给 DSH 的生成可以用原生停止键停止。
- 开关是浏览器或桌面 WebView 的本地设置。未发送的片段在当前页面的内存里，切换会话可以回来继续，刷新或退出会清掉。发送后，内容按 DSH 的正常会话记录和模型设置处理。
- 第一版的分段缓冲支持纯文本。带附件、引用、斜杠命令及 Ctrl/Cmd+Enter 仍走 DSH 自己的发送流程。若有待发送片段，先点「我说完了」可以保持对话顺序。
- 「主动搭话」继续按自己的设置运行。可以把它限定在另一个会话。

## 可选的记忆宫殿联动

[记忆宫殿 `@kenz1117/dsh-engram`](https://github.com/kenz1117/dsh-engram) 是独立插件。它在当前 profile 可用时，工具栏会显示「记住长期偏好」。这个开关默认关闭，按会话保存。开启后，完整回复结束时，宿主会再次确认 Engram 已启用并且当前会话能执行 `engram_save`，再把提炼出的偏好写入 `user` 库。联动使用 DSH 原生工具执行器及其审批策略。当前首版的自动写入已在标准模式和 Engram 0.13.10 验证，PTC 会话的自动写入尚未适配。

目前只识别明确说出来的几类聊天偏好，例如想先讲完、想先聊感受、建议前先问、希望一次只问一个问题。写入内容是对应的简短归纳，故事原文和人物信息不会作为这个联动的工具参数。「这段别记」一类表达会跳过本轮的联动。Engram 自带的自动摄取由它自己的设置控制，也可能读取普通 DSH 聊天记录。

## 开发与打包

```sh
npm test
npm pack
```

浏览器包由 `npm run build` 生成。包体包含源码和测试。要发布到 GitHub Releases，可以上传生成的 `.tgz` 作为安装附件。许可证为 MIT。
